# 让每日阅读变成可追溯的创作素材

每天看到的信息很多。真正值得留下的，不只是一句看似精彩的观点，还有它从哪里来、什么时候发布、是否适合当前选题。

## 从收集开始，保留来源

编辑在整理素材时，可以把文章标题、发布时间与原文链接一起保存。这样后续写作时，就能回到原文核对事实，而不是只凭一段转述下判断。

本演示使用两篇虚构文章：《从信息收集到内容创作：让资料真正用起来》和《一个好的写作工具，应该保留哪些人工判断》。它们只存在于软件的本地演示数据中。

## 让工具整理，让编辑判断

工具可以帮助归档、摘要和组织草稿。选题是否成立、事实是否充分、表达是否适合读者，仍由编辑负责判断。

因此，稿件完成后先进入待审核状态。审核者可以查看素材报告，修改标题与正文，确认后再导出。

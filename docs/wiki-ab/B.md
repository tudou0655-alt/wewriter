# 2025家电以旧换新补贴，购买前先核对这几项

面向个人消费者：资料称，2025年购买12类符合条件的家电可享以旧换新补贴；购买前应先核对商品是否在适用范围内。[S1]

### 先看品类和可补件数
相关资料称，补贴按人、按品类计算，通常每人每类可补贴1件；空调例外，每人最多可补贴3件。每件产品补贴上限为2000元。[S3] 资料还称，即使个人消费者2024年已享受过某一类家电补贴，2025年购买该类家电仍可再次享受。[S2]

### 再算补贴金额
行业资料称，二级能效或水效产品按最终售价的15%补贴，一级产品按20%补贴。[S1] 购买前可用“最终售价×适用比例”估算，再核对是否超过每件2000元的上限。[S1][S3] 比较商品时，除了标价，还要确认最终售价、能效或水效等级，以及自己是否符合对应品类的件数条件。具体哪些商品适用，需按购买地的实际信息核对；现有资料未列出12类家电名单。

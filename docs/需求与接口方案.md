# 公众号采集与文章生成 Windows 软件

更新日期：2026-10-10。已实现 Windows 试用版；本文保留设计依据，实际使用与限制见根目录 README.md。尚未完成真实 API 凭据联调。

## 已确认需求

- 安装在客户 Windows 电脑运行。
- 客户自行添加、删除、启停公众号，初期十几个公众号。
- 公众号数据来源：EveryInfra。
- 模型：Qwen Flash、DeepSeek V4.1 Flash，支持选择。
- 每天定时采集、总结文章并生成新文章。

## 暂定默认值

- 每日共采集约 10 篇原文，生成 1 篇草稿；此数量解释尚待确认，均设计为可配置。
- Qwen Flash 用于逐篇摘要，DeepSeek V4.1 Flash 用于综合写作；属于初始分工，并非质量评测结论。各阶段允许用户切换模型。
- 初版提供本地查看、编辑及导出，不包含自动发布或邮件推送。
- 写作行业、字数、风格作为任务配置，不写死。

## 运行结构与数据边界

Windows 界面 → 本地任务执行器 → EveryInfra 适配器 → 清洗去重 → 本地数据库 → 摘要模型 → 写作模型 → 草稿审核与导出。

文章、任务记录和稿件保存在客户电脑；采集请求发送至 EveryInfra；用于摘要的正文和用于写作的摘要、来源片段会发送到所选模型服务，不能称为全离线系统。

主窗口关闭可选择最小化到托盘。开机启动由用户设置。保存调度时区与下一次执行时间，重启或休眠恢复后检测遗漏任务；默认合并为一次补执行，避免累积重复调用。退出进程或电脑关机期间无法执行任务。

## 接口核实

### EveryInfra

- 文档：https://everyinfra.com/docs
- Base URL：`https://api.everyinfra.com`
- 鉴权：`Authorization: Bearer <API_KEY>`。
- 统一数据端点：`POST /api/v1/social`，请求包含 `platform`、`action`、`params`。
- 能力目录：`GET /api/v1/social/catalog`。
- 已读取公开目录：公众号平台为 `wechat_oa`，使用 `account_articles`，参数为 `account` 与 `limit`，返回 `results` 和 `posted_at` 等字段。目录快照见 everyinfra-wechat.json。
- `account_today_articles` 的 supply_note 当时标注暂不可用，使用历史文章列表在本地筛选时间窗。
- 正文通过 `POST /api/v1/search` 的 `read` 工具获取，只接受 `results[].content`，不使用 snippet 代替正文。规范说明 content 可能为全文或节选，需真实样本验证完整性。
- 尚未验证真实账号覆盖率、提取完整性和付费账户权限，不承诺全量监控。

### Qwen Flash

- 模型 ID：`qwen-flash`。
- 文档：https://help.aliyun.com/zh/model-studio/qwen-flash
- 按客户阿里云百炼账户地域和工作空间配置 Base URL 与 API Key。
- 摘要结构化输出需要校验格式，失败时有限重试，不将空结果视为成功。

### DeepSeek V4.1 Flash

- 官方 API 模型 ID：`deepseek-flash`。
- 官方 Base URL：`https://api.deepseek.com`。
- 文档：https://api-docs.deepseek.com/
- 更新说明：https://api-docs.deepseek.com/updates/
- 模型供应商与模型 ID 分开配置。若用户通过其他供应商调用，需要按该供应商文档映射，不直接套用官方 ID。

## 数据对象

- accounts：本地 ID、供应商账号标识、名称、启用状态、同步游标。
- articles：本地 ID、供应商文章 ID、账号 ID、标题、原文 URL、发布时间、采集时间、正文、内容哈希。
- analyses：文章 ID、模型与供应商、提示词版本、摘要、事实及来源片段、处理状态。
- jobs：任务 ID、调度时间、时区、采集窗口、配置快照、阶段状态、错误、重试次数。
- drafts：稿件 ID、任务 ID、来源文章 ID、大纲、标题、正文、模型信息、版本与审核状态。
- settings：调度、数量限制、写作要求及密钥引用；密钥不明文放入普通配置、日志或导出文件。

删除关注账号默认停止后续同步并保留历史文章，历史数据清除作为独立操作。

## 执行与验收要求

1. 公众号增删启停可持久化，重启后保持配置。
2. 对同一文章和同一计划任务建立唯一标识，重试不重复入库或生成。
3. 采集、摘要、写作分别保存状态，失败从对应阶段恢复。
4. 明确区分无新文章、部分采集失败、全部采集失败和素材不足。
5. 限流与暂时故障使用有上限的退避重试；鉴权、余额问题停止并提示，避免无限消耗。
6. 模型阶段可切换，但默认不静默跨供应商发送素材。
7. 将原文视为待分析数据，忽略原文中要求改写系统规则、调用工具或泄露密钥的指令。
8. 稿件关键事实保留来源映射；冲突信息标记待核实；检查只能辅助审核，不能保证事实正确。
9. 无密钥时可验证本地配置和流程；真实接口、采集覆盖率、生成质量及 Windows 安装包必须单独验收。

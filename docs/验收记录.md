- 29 项自动化测试通过：定时时区与补执行、输入校验、URL 去重、采集失败状态、摘要断点复用、重复生成防护、素材不足、模型引用格式、接口错误与有限重试、Windows DPAPI 密钥加解密、数据库备份恢复、稿件版本保存。

- EveryInfra 公开能力目录、正文工具目录、OpenAPI 规范已下载留档。没有使用真实 API Key，没有发生付费采集或模型调用。

## 交付边界

当前版本每个任务生成 1 篇草稿，支持 Markdown/TXT 导出。数据库随应用使用，无需独立数据库服务。未包含自动发布、邮件推送、Word 导出或共享服务器。EXE 未做代码签名，尚未在客户机器上验收。

# 全过程工程咨询不是补贴申报｜政府投资项目优先开展，企业应提前配置负责人

全过程工程咨询正在从行业倡导走向更具体的项目采购和合同安排，但它不是一项可以等待统一补贴比例、投资门槛或申报截止时间的专项资金政策。对咨询、设计、监理、造价和项目管理企业而言，机会主要来自政府投资、国企投资及房建市政项目的全过程咨询采购；企业现在要准备的，也不是补贴申报材料，而是能否进入项目资格审查和履约体系。

## 国家文件的变化：从房建市政延伸到跨阶段服务

全过程工程咨询，可以理解为业主将投资决策、设计、建设管理、造价、监理等多个阶段或专业服务，交由一家机构或多家机构联合组织实施。它并不意味着所有专业工作都必须由一家公司完成，关键在于服务边界、责任接口和项目组织能否统筹。

2019年3月15日，国家发展改革委、住房城乡建设部印发《关于推进全过程工程咨询服务发展的指导意见》（发改投资规〔2019〕515号）。文件重点面向房屋建筑和市政基础设施领域：政府投资项目优先采取投资决策综合性咨询，并鼓励政府投资、国企投资项目带头采用工程建设全过程咨询。

2025年9月13日，国家发展改革委办公厅印发《关于加快推动工程咨询行业高质量发展的意见》（发改办投资〔2025〕824号）。文件提出，在投资决策、勘察设计、建设、运营维护等环节支持跨阶段、一体化服务，并提出政府投资项目优先开展全过程工程咨询。

两份文件可作如下理解：2019年文件的落点更集中于房建市政领域和工程建设全过程咨询；2025年文件则把视角延伸至工程咨询行业的跨阶段服务能力，覆盖投资决策到运营维护的更多环节。对企业来说，房建、市政项目仍要重点对照2019年文件；计划把业务向前期决策、建设管理或运营维护延伸的机构，则应同步关注2025年的一体化服务导向。

| 对比维度 | 2019年文件 | 2025年文件 |
|---|---|---|
| 主要着眼点 | 房屋建筑和市政基础设施 | 工程咨询行业高质量发展 |
| 项目导向 | 政府、国企投资项目带头采用 | 政府投资项目优先开展 |
| 服务组织 | 综合能力机构实施或多家机构联合 | 跨阶段、一体化及多专业组合服务 |

## 先纠正一个误区：没有全国统一补贴窗口

上述国家文件没有为全过程工程咨询设置全国统一的财政补贴比例、企业投资额门槛、专项资金申报窗口或截止时间。因此，不能把全过程工程咨询纳入超长期特别国债、中央预算内投资或一般产业补贴项目的申报逻辑中理解。

费用安排仍要回到项目投资和合同。2019年文件明确，咨询费可以在项目投资中列支，也可以由其中包含的投资咨询、设计、监理、造价、项目管理等费用支付；计费可采用专项费用叠加并增加统筹管理费，或按人工成本加酬金方式确定。

国家2024版全过程工程咨询服务合同示范文本为推荐性使用，适用于房屋建筑和市政基础设施项目；服务内容和价格需要在具体合同中约定，并不存在全国统一收费标准。

这意味着，企业跟踪机会时应先看招标文件，而不是先问有没有补贴。尤其要拆清服务范围是否延伸至前期策划、可研及报批、设计管理、招采、造价、监理、竣工移交或运营评价。服务阶段越长，责任、人员投入、变更和付款安排越不能沿用单项咨询项目的报价习惯。

## 能否参与，先看四项准入与履约条件

2025年文件支持甲级资信工程咨询机构发挥一体化服务示范作用，并探索投资咨询、工程管理和专项咨询的集成服务模式；同时，也鼓励中小机构开展跨阶段或同阶段多专业组合服务。

但政策支持不等于甲级资信成为所有项目的法定准入条件。具体项目需要什么资质、业绩、负责人和联合体安排，仍须以招标文件为准。

企业至少应提前核对四项：

1. **服务与资质是否匹配。** 实际承接勘察、设计、监理或造价咨询等业务的，应具备与工程规模、委托内容相适应的资质。
2. **项目负责人能否满足条件。** 2019年文件明确，工程建设全过程咨询项目负责人应具有工程建设类注册执业资格、工程类或工程经济类高级职称及类似工程经验。
3. **联合体是否有清晰责任边界。** 文件允许一家综合能力机构实施，也允许多家机构联合实施。企业不能只在投标前临时拼接证书，还应事先明确牵头方、专业接口、成果责任、人员到岗和违约承担。
4. **是否存在利益冲突。** 全过程咨询单位与同一项目的工程总承包、施工、材料设备供应单位之间不得存在利害关系。参与决策前应先完成关联关系排查。

## 地方执行已出现差异，不能跨行业、跨地区套用

福建已形成较明确的地方执行口径。福建省住房和城乡建设厅印发的闽建〔2024〕22号文件《福建省房屋建筑和市政基础设施项目工程建设全过程咨询管理规定（试行）》自2025年5月1日起执行，目前官方标注为有效，并同步发布2024年版标准招标文件。

这意味着，在福建开展房建、市政业务时，企业除关注项目公告外，还应提前研究标准招标文件中的服务范围、人员配置、评标和合同条款。但该规定的边界同样明确：它面向福建省房屋建筑和市政基础设施项目，交通、水利、电力等行业项目及其他省份项目，不能当然照搬。

至于四川有关实施意见的征求意见信息，现有材料未能核实对应主管部门公告和后续正式发布状态。在正式文件、文号及施行日期明确前，不宜把它当作已经生效的市场准入、收费或采购规则。

## 企业现在怎么排期

建议按项目获取、投标、履约三个阶段倒排，而不是等待所谓专项申报通知。

项目获取阶段，应建立政府投资、国企投资项目跟踪表，标记项目所在地、行业、建设阶段和可能打包的咨询内容。房建、市政项目可重点核对当地住建部门管理规定及标准文本；其他行业则以行业主管部门要求和具体招标文件为准。

投标阶段，应先锁定能够满足注册资格、高级职称和类似业绩要求的项目负责人，再盘点本企业可独立覆盖的专业、必须联合的专业以及可用于证明服务能力的既有业绩。单一设计、监理或造价业绩能否被认可，不能自行推定，仍要看项目资格条件和评审规则。

假设某项目同时覆盖前期咨询、设计管理、造价和监理，单家企业不能覆盖全部委托内容时，应在公告前明确联合体牵头方、专业边界、人员配置与责任分工。报价同步拆分基础服务、增值服务、业主配合事项、变更计价和付款节点，避免用单项服务的低价逻辑承接跨阶段合同。

全过程工程咨询的政策导向已经明确，但它不是一份等待申报的补贴清单。真正决定企业能否拿到订单的，是能否在下一轮招标前完成负责人储备、专业组合、联合体机制和合同风险控制，并针对项目所在地和行业口径逐项核验。
